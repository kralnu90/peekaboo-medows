# Peekaboo Meadow

A gentle tap-and-find game for little ones, from **Kralnu Games**. [kralnugames.com/kids](https://kralnugames.com/kids/)

Everything in the meadow does something when you tap it: animals pop out of the bushes, the sun giggles, clouds rain flowers and balloons float up to be popped. A friendly voice asks "Can you find the fox?" with a picture, so no reading is needed. Finding it earns a star, and five stars starts a balloon party. Nobody ever loses.

- No ads, no chat, nothing to buy, no data collected
- Works in any phone or tablet browser
- A press-and-hold grown-ups button turns the sounds, the voice and the find-it game on or off

## Play

Open `index.html` in a browser, or turn on GitHub Pages for this repo (Settings → Pages → Deploy from branch → `main`, root folder).

Everything is drawn in SVG and every sound is generated in the browser, so there are no image or audio files.
