# Peekaboo Meadow

A gentle tap-and-find game for little ones, from **Kralnu Games**. [kralnugames.com/kids](https://kralnugames.com/kids/)

Pick a place to visit: the **meadow**, the **farm** or the **beach**. Everything does something when you tap it: animals pop out of their hiding places, the sun giggles, clouds rain flowers and balloons float up to be popped. A friendly voice asks "Can you find the duck?" with a picture, so no reading is needed. Finding it earns a star, and five stars starts a balloon party. Nobody ever loses.

- **Three places, fifteen animals:** a bunny, hedgehog, fox, frog and bird in the meadow; a cow, pig, sheep, chick and duck on the farm; a crab, turtle, seal, dolphin and seagull at the beach
- **Colouring:** eight pictures to colour in with twelve big, bright colours (purple included, of course). The voice names each colour as it's picked
- **Bedtime wind-down:** tap the moon, or set it to happen after a set amount of play. The sun sets, the scene gets dark, the moon and stars come out, and each animal says goodnight and falls asleep. Tap the sun to wake everyone up again
- No ads, no chat, nothing to buy, no data collected
- Works in any phone or tablet browser
- A press-and-hold grown-ups button turns the sounds, the voice, the find-it game and the bedtime timer on or off
- **Record your own voice:** grown-ups can record the lines ("Can you find the bunny?", "Night night, bunny") so little ones hear a familiar voice. Recordings stay on the device
- A voice chooser, plus step-by-step help for downloading better voices on Android and iPhone

## Play

Open `index.html` in a browser, or turn on GitHub Pages for this repo (Settings → Pages → Deploy from branch → `main`, root folder).

Everything is drawn in SVG and every sound is generated in the browser, so there are no image or audio files.

## Updates

The game checks for a newer version when it opens and when you come back to it. If there is one, players see a small "A new version is ready" notice with an **Update** button, and there's a **Get the latest version** button in the menu at any time.

When pushing an update: change the game's version number and put the same value in `version.json`.
